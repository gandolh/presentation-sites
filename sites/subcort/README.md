# subcort — Subcort

**Demo** presentation site for an **event-tent rental and setup service** in
Gorj / Oltenia: tent brought to the client's own location, mounted to plan,
floored, lit, heated or cooled by season. Romanian, multi-page, static.

Informational by design — [`PRODUCT.md`](PRODUCT.md) records the deliberate
decision that the site carries **no calls-to-action**.

Astro 6 · React 19 islands · Tailwind v4 · deployed under the sub-path
`/subcort`.

## Run it

> This site is an **npm workspace**. Install once from the repo root
> (`npm install` there) — dependencies hoist to the root `node_modules/`, and
> the commands below work from this directory or via the root passthroughs
> (`npm run subcort:dev`).

```bash
npm run dev              # placeholder imagery (the default — there are no real photos)
npm run dev:real         # real photos, if any are ever dropped into public/images/real/
npm run build
npm run placeholders     # regenerate the illustrated SVG placeholders
```

Build for the sub-path the way the VPS serves it:

```bash
PUBLIC_BASE=/subcort npm run build
```

## Imagery

Two committed sources, both placeholders since this is a demo:

- `public/images/*.svg` — illustrated scenes generated by
  [`scripts/gen-placeholders.mjs`](scripts/gen-placeholders.mjs).
- `public/images/photos/*.jpg` — neutral gallery photos, listed in
  [`src/content/gallery.ts`](src/content/gallery.ts).

`public/images/real/` exists but is empty and git-ignored, ready for real photos.
The favicon is hand-maintained at `public/favicon.svg` and is **not** generated.
