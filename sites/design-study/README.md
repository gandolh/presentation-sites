# design-study — Fourteen Renderings

A UI/UX study built as a working site: **one blog, fourteen design languages**.
The same twelve posts, the same words, the same photographs, rendered in
Minimalism, Swiss, Brutalism, NeoBrutalism, Maximalism, Surrealism, Bohemian,
Ethereal, Skeuomorphism, Neumorphism, Claymorphism, Glassmorphism, Liquid Glass
and Spatial UI.

The content is the control variable. Everything that changes between pages is
design.

Deploy sub-path: **`/design-study`**.

## Run it

```bash
# from the repo root
npm run design-study:dev
npm run design-study:build
npm run design-study:preview
npm run design-study:placeholders   # regenerate the 18 image placeholders
```

Astro 7 + React islands, static output, **no Tailwind** — unlike its sibling
sites. Fourteen hand-authored visual systems share no utility vocabulary, and
Tailwind's preflight actively fights the Brutalism theme, whose entire position
is "browser defaults, untouched".

## How it is put together

```
src/
  content/
    styles.ts     the 14 styles — single source of truth for routing
    posts.ts      the 12 posts, as structured blocks (not markdown strings)
    images.ts     the repo-standard mock/real image pipeline
    site.ts       the fictional publication
  themes/<slug>/
    Shell.astro   page chrome; imports this theme's fonts + CSS
    Feed.astro    the paginated index
    Post.astro    carousel first, then the body
    theme.css     everything visual, scoped under .ds-page
    meta.ts       swatch + scheme for the neutral gallery
    Carousel.tsx  OPTIONAL — only spatial/ and liquid-glass/ ship one
  pages/<slug>/   two thin route files per theme (see below)
  components/     the shared carousel island, pager and neutral switcher
```

### Three decisions worth knowing before you edit

**1. Route files are deliberately repetitive.** There are 28 near-identical
four-line files under `src/pages/<slug>/`. A single `[theme]` route resolving
components from a registry was tried first and measured: every page ended up
linking every theme's stylesheet, because Astro collects CSS from a page's
whole module graph whether or not a component renders. Static imports are what
keep a visitor to `/swiss/` from downloading Maximalism's fonts.
`scripts/check-routes.mjs` runs on `prebuild` and fails if a style in
`styles.ts` has no theme directory or route files.

**2. Themes scope everything under `.ds-page`.** The neutral switcher lives
outside it, as a direct child of `<body>`, so no theme rule can reach it. Break
that and the chrome starts wearing the theme it is supposed to be measuring.

**3. Post pages are carousel-first, everywhere.** That is the control variable.
A theme may change the carousel's size, bleed and framing; it may not move it
below the text.

### Post body is structured blocks

`posts.ts` stores `{ type: "p" | "h2" | "quote" | "list" | "aside" }`, not
markdown. Full per-theme rendering means Brutalism can slam a pull-quote across
the full bleed while Ethereal lets the same quote float in thin serif — which
is impossible if the body arrives as pre-rendered HTML.

### Images

Eighteen shared placeholders under `public/images/`, generated by
`scripts/gen-placeholders.mjs` and built to survive being filtered fourteen
different ways — full tonal range, a legible subject shape, and grain. Drop
real photography into `public/images/real/`, list the names in
`src/content/images.ts`, and build with `PUBLIC_IMAGE_SOURCE=real`.

## The written study

The site carries no commentary — it is a skin gallery on purpose. The analysis
lives in **[docs/styles/](docs/styles/)**, one dossier per language, each with
a copy-pasteable **image treatment** recipe and a bag of **prompt descriptors**
for generating imagery in that style. See
[docs/styles/README.md](docs/styles/README.md).

## Navigation

A neutral bar on every page: prev / current / next, a grid button for the full
picker, and <kbd>←</kbd> <kbd>→</kbd> (or <kbd>[</kbd> <kbd>]</kbd>) to step,
<kbd>G</kbd> for the list. **Switching preserves position** — from
`/swiss/borrowed-light/` the next theme is `/brutalism/borrowed-light/`, so the
same post can be compared across all fourteen.
