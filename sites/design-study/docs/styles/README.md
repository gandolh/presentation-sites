# The style dossiers

One file per design language, fourteen in all. Each is written to do two jobs:

1. **Explain the style well enough to build it** — where it came from, what its
   actual rules are (as opposed to what it looks like), the palette, the type,
   the surface treatment, and the accessibility bill it comes with.
2. **Serve as an image-generation brief.** Two sections in every file carry
   that load: **Image treatment** (the CSS recipe applied to photography in
   this style, copy-pasteable) and **Prompt descriptors** (a compact bag of
   concrete visual terms for an image model). Those two sections are why the
   dossiers exist in this form rather than as inline site copy.

The site itself carries no commentary — it is a skin gallery, by design. All
the analysis lives here.
