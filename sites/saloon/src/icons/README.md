# Local icons

Drop site-specific `.svg` files here to use them as `<Icon name="filename" />`.

Everything currently on the site comes from Phosphor via `@iconify-json/ph`
(`<Icon name="ph:whatsapp-logo" />`), so this directory is empty — but
`astro-icon` scans it on every build and warns if it is missing, so it stays
checked in.
