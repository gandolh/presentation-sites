Direction · The porch notice

The page opens the way a church door does: the parish's name and its picture on a burgundy band, the program pinned on a raised board that rises out of the band, the account beside it. One look, no dark palette (parish sites keep the one look designed for each church), so the sheet sets the parish's seeds beside a second parish's seeds where other sheets set light beside dark. Every other colour is derived from the four seeds.

Program: more than two rows

The day cards grow downward and a long list never scrolls inside its card. The template has no string for an empty schedule: the code brief decides whether to hide the card.

Loading

None. The site is static per build, so no screen waits on data; the pomelnice send shows Se trimite… above.

Contrast

Computed from the derived values for both parishes. Text needs 4.5, UI parts and the focus ring 3, and a card must differ from the page by 1.09 or carry an edge of 1.3. Pure gold or silver on white is under 3, so it is kept for rules and the arch line on the primary; every icon on a light surface takes secondary-strong, gated at 3.
