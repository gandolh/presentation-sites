# Task 10 — Raster social cards for saloon, subcort and tractari

## Context

Audit 2026-09-27 (see [log](../../log.md)). Facebook, WhatsApp, X, LinkedIn,
Slack and iMessage do not render an SVG `og:image`. auto-service already
records this in `sites/auto-service/scripts/og-card.html:4-9` and ships a PNG.
The other three sites do not:

- **saloon** — `public/images/og-image.svg` is a 561-byte gradient with the
  words "Ana Saloon" set in Playfair Display. The site is branded "Unghii by Ana"
  (`src/content/site.ts:12`) and uses Fraunces + Manrope, so even where an SVG
  renders, the card is off-brand. WhatsApp is this site's entire booking
  channel, so this is the card people will actually share.
- **subcort** — `public/images/og-image.svg` is generated by `scripts/gen-og.mjs`
  from the marquee model in `src/lib/draft.ts`. The drawing is good; only the
  format is wrong.
- **tractari** — has no card at all.

## Files you OWN

- saloon: `public/images/og-image.png` (new), a source under `scripts/` (e.g. `scripts/og-card.html`), the og path in `src/layouts/Base.astro`, and the old `public/images/og-image.svg`
- subcort: `scripts/gen-og.mjs`, `public/images/og-image.png` (new), the og path in `src/layouts/Base.astro`
- tractari: `public/images/og-image.png` (new), `scripts/og-card.html` (new), the og tags in `src/layouts/Base.astro`

## Files you must NOT touch

- auto-service (already done) and design-study (`noindex` by decision).
- The mock/real image pipeline. The card is not a photo and must not resolve
  through `img()` / `hasReal`. Reference it directly, the way auto-service does:
  `withBase("/images/og-image.png")`, or `absoluteUrl()` once Task 09 lands.

## What to do

Author each card in that site's own design language, so read the site's
`DESIGN.md` first:

- saloon: blush-cream and gold, Fraunces / Manrope;
- subcort: ink drawing, a single orange `#C2481E` for annotation, IBM Plex;
- tractari: night palette, Big Shoulders Display + Archivo.

Use the **real self-hosted faces**, so the Romanian diacritics (ă â î ș ț)
render correctly. Follow auto-service's `scripts/og-card.html` approach: an HTML
source that loads the fonts from the root `node_modules`, screenshotted at
exactly 1200×630.

For subcort you may instead rasterize the generated SVG with `sharp`, which is
already installed. Check the diacritics in the PNG: if they fall back to another
font, use the HTML route.

Output a 1200×630 PNG **under 300 KB**, since WhatsApp drops larger preview
images. Keep each source next to its PNG, with a one-line "to regenerate" note
inside it.

Depends on Task 09: the card only shows in previews once the tag is absolute.

## Acceptance

- `file sites/{saloon,subcort,tractari}/public/images/og-image.png` → each is a 1200 x 630 PNG under 300 KB.
- In each built `dist/index.html`, `og:image` and `twitter:image` end in `og-image.png` (and are absolute once Task 09 is in).
- Open each PNG and check it: the brand name matches `site.name`, the
  diacritics are correct, and the text is readable at the ~500px width a chat
  preview uses.
- No page head references `og-image.svg`.

## Outcome — 2026-10-02

Every card is an HTML source screenshotted by headless Chrome at 1200×630, using
the site's own self-hosted faces from the root `node_modules`, and stored as a
palette PNG:

| Site | Source | PNG |
|---|---|---|
| saloon | `scripts/og-card.html`: blush-cream, one gold hairline, Fraunces (SOFT) + Manrope, the brand "Unghii by Ana" and the site's own tagline | 19 KB |
| subcort | `scripts/gen-og.mjs` (`npm run subcort:og`) now writes `scripts/og-card.html` (the same marquee drawing, wrapped with the IBM Plex faces), runs Chrome, palette-encodes with `sharp`, and fails if the size is not 1200×630. The marquee moved 25 px right, clear of the headline. | 26 KB |
| tractari | `scripts/og-card.html` (new): night asphalt, an amber→orange lane line running to the horizon with reflector posts, Big Shoulders Display + Archivo, the hero's copy, the five counties and a safety-orange "Sună acum" | 112 KB |

The `sharp` route for subcort was ruled out first: IBM Plex is not installed
system-wide, so librsvg would have set the type in a fallback face.

Each head points `og:image`, `twitter:image` and the JSON-LD `image` at
`absoluteUrl("/images/og-image.png")`, so no card goes through `img()`. tractari
gained all three and is back to `summary_large_image`. The two old SVG cards are
deleted, along with saloon's `gen-placeholders.mjs` block that produced one
labelled "Ana Saloon". The pipeline notes in saloon's `public/images/real/README.md`
and subcort's README are updated to match.

Verified: `file` shows each PNG is 1200 x 630 and under 300 KB. Each was opened
and checked: the name matches `site.name`, and ă â î ș ț render in the brand
face. On tractari, the breve on "PLATFORMĂ" collided with the line above until
the headline lines were spaced apart. `PUBLIC_BASE=/<site>` builds emit
absolute `…/og-image.png` tags. No built page references `og-image.svg`.
`astro check` is clean in all three.
