# showcase

A look-don't-touch gallery of the marketing sites in this monorepo, under the
handle **gandolh**. The whole page is one running terminal session: the handle
and craft line print as stdout, then `ls ./projects` "outputs" the five sites —
each row a screenshot plate linking to its live deployment.

Astro (static, no UI framework) + Tailwind v4. Deploys under `/showcase` on the
shared VPS alongside the sites it shows.

## Develop

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # → dist/
npm run preview
```

## Screenshots

Tiles read from `public/shots/<slug>.png`. They currently hold branded
placeholders generated by `scripts/make-placeholders.mjs` (requires ImageMagick).
Drop a real capture in at the same path and it appears with zero code changes.

## Live-site links

Each tile links to `${PUBLIC_SITES_HOST}/<slug>` (e.g. `/saloon`). At build time
the deploy injects `PUBLIC_SITES_HOST` (the VPS origin); if unset, links fall
back to same-origin relative paths, which resolve on the VPS itself.

To add or change a project, edit `src/content/projects.ts`.
